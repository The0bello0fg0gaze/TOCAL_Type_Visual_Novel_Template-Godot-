# Spooktober VN

Hey! This is a visual novel project I'm putting together using Godot 4. It was originally spun up as a base for the Spooktober visual novel jam, but the template and systems here can honestly be used for pretty much any narrative-driven game.

### What's in here?
- A basic dialogue system handling text and character choices.
- Scene management (smooth transitions from the main menu into the game levels).
- A clean Godot 4 project structure. It uses the GL Compatibility renderer, so it should run smoothly on older hardware or web exports.

### Controls
You can play it with a keyboard or a controller:
- **Accept / Next Line:** Space, Enter, E, or the A button on a gamepad
- **Move around:** WASD / Arrow keys or D-pad
- **Menu / Pause:** Escape

### Getting Started
If you want to poke around the code or run it locally:
1. Make sure you have Godot 4.x installed.
2. Clone this repo.
3. Open Godot, click Import, and point it to the `project.godot` file.
4. Hit F5 to run!
